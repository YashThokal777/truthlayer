# Upgrade to Pro

Outgrowing the Free plan? Here is what changes when you upgrade.

## What you get

- The Pro plan costs $29 per month, billed monthly.
- No project limit. The Free plan includes 10 projects.
- Up to 25 team members.

## API limits

Pro workspaces use the same API as everyone else. The API rate limit is 100 requests per minute per API key.

To see how much you used last month, call `GET /v1/reports`.

## How to upgrade

1. Open **Settings → Billing**.
2. Click **Upgrade to Pro**.
3. Enter your payment details and confirm.
