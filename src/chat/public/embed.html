Sample site for the widget demo

This is what the chat looks like on your website

Pretend this is your product's site. The chat button sits in the bottom-right corner. Click it and ask something.

Add it with two lines

<script src="https://YOUR-SERVER/widget.js"></script>
<truthlayer-chat endpoint="https://YOUR-SERVER" accent="#0f766e"></truthlayer-chat>

Make it yours

AttributeWhat it does
accentYour brand color. This demo uses teal: #0f766e.
modebubble (floating button) or inline (fills a box on the page).
titleThe name in the chat header.
themelight or dark. By default it follows the visitor's system setting.
